# 墨水阅读（app-ink-reader）

仿墨水屏观感的纯离线 epub 阅读器，面向旧手机（minSdk 21 / Android 5.0）。

## MVP 功能

| 功能 | 说明 |
|---|---|
| 打开本地 epub | 系统文件选择器，**零权限**（不需要存储权限） |
| 书架 | 导入过的书都存在私有目录里，入口页列出全部，按导入时间倒序；**支持多本书**（进度、笔记各自独立） |
| 翻页 | **左右滑动**（右→左下一页 / 左→右上一页，横向位移达屏宽 22% 即触发，一次按压只翻一页）；点亮屏左 1/3 上一页、右 1/3 下一页；音量键也能翻；跨章自动衔接 |
| 章节目录 | 按 EPUB 标准目录（NCX / nav）生成，**支持一文件多章**（Kindle 转换书的锚点片断），点击跳到该章所在页 |
| 字号 | 4 档（18 / 20 / 22 / 24 sp），改完按进度比例还原位置 |
| 进度记忆 | 记住看到第几章第几页，重进自动恢复 |
| 电量 | 底部状态条显示（复用项目二的电池广播读取） |
| 全屏正文 | 默认只剩文字；点屏幕中部，章节名（顶）+ 页码电量（底）+ 工具条（底）一起浮出，再点一起消失 |
| 纯离线 | **不申请 INTERNET 权限**，飞行模式可用 |

## 测试用样例书

| 用途 | 书 |
|---|---|
| 快速验证全链路 | Release v1.0 附件里的 `guwen.epub`（《古文五篇》，5 章公有领域古文） |
| 目录基准对比 | 《纳瓦尔宝典》《我看见的世界》《无穷的开始》（都在 `../epub_book/`） |

后面三本是刻意留的**难例**：分别对应「NCX 乱码」「一章被切成多个文件」「多章挤在一个文件里」三种烂数据，它们的目录解析正确性见《收尾归档》里的坑表。

## 笔记与导出

- **划线**：长按正文 → 选中整句 → 底部浮出选区条 → 拖把手调整首尾 → 「写笔记」
  （**不自动弹框**：先让用户调选区，实测直接弹框会让人以为只能选一句话）
- **留空也能确认** = 只划线，不写笔记
- **查看 / 修改 / 删除**：点已划线的句子直接打开笔记框
- **定位主键**：章内字符偏移 `(chapter, start, end)`，改字号后位置依然准确（页码会变，不能当主键）
- **笔记面板**：工具条「笔记」→ App 内直接看全部笔记，**点条目跳回原文位置**（连选区一起高亮）
  导出按钮也在这个面板里 —— 能在 App 里看，导出就降为低频操作
- **面板内排版**：md 式三层展开 —— 章节（17sp 粗体）/ 摘要（14sp）/ 笔记正文（13sp），**完整显示不截断**
- **有选区时点正文空白处** → 选区和选区条一起消失，不用手动点「取消」

导出格式（章节分组 + 摘要作标题，Obsidian 里可直接在大纲中跳转）：

```
## 推荐序一
### 大家都能学会的东西是不可能让你致富的。
笔记正文（没写笔记就空着）

### 另一句摘要
```

- **导出**：笔记面板「导出 md」→ 选位置，默认名 `书名.md`，**同名即覆盖**

## 墨水屏观感：只借鉴了两件事

参考的是一份"模拟墨水屏"网页。它 80% 的工夫是"看起来像设备"，对真机阅读器只有**配色**和**排版**是净收益：

| 采纳 | 值 | 理由 |
|---|---|---|
| 纸张底色 | `#B8B6B5` | **色相由照片实测定**（两次逐像素统计均为 R≈G≈B 的中性灰，网页的 `#e8e6e0` 与我们的初版 `#F0ECE3` 都偏暖，色相是错的）；**亮度由目视定**——两次照片测得 `#D7D6D6` / `#B4B2B2`，差 30+ 灰阶，环境光与曝光的影响远大于屏幕本身，追照片会越调越乱 |
| 文字色 | `#2B2B2B` | 纯黑对比过强易眩光 |
| 行高 / 字距 | 1.7 / 0.02 | 影响阅读节奏 |
| 首行缩进 | 2 字符 | 中文排版习惯 |

| 丢弃 | 理由 |
|---|---|
| 灰度滤镜 | 我们本来就只渲染黑白文字，没有彩色可去 |
| 噪点纹理 / 暗角 | 自发光屏上无意义，还降低可读性 |
| 残影层 / 刷新按钮 | 只有真墨水屏硬件才需要全刷 |
| 首字下沉 | 西文排版习惯，中文用首行缩进 |
| 两端对齐 | API 26+ 才有，minSdk 21 用不了 |

## 技术方案

```
打开文件（ACTION_OPEN_DOCUMENT，零权限）
  → 复制到私有目录（EPUB 是 ZIP，必须随机访问）
  → ZipFile → container.xml → content.opf → spine 顺序 → 各章 XHTML
  → 清洗 HTML → Html.fromHtml（含 ImageGetter 读 zip 内图片）
  → StaticLayout 分页 → 自绘 View 翻页
```

| 决策 | 选择 | 理由 |
|---|---|---|
| EPUB 解析 | **自研**（ZipFile + 正则解析 OPF，约 300 行） | 不引第三方库：省体积、编译快、老手机跑得动 |
| 渲染 | **自绘 View + StaticLayout** | 不用 WebView：旧手机上太重；分页精确才能显示总页数 |
| 依赖 | **只有 androidx.core-ktx** | 与项目一 / 二一致的最小依赖原则 |
| 打开方式 | **Storage Access Framework** | 零权限 |
| 权限 | **无** | 连 INTERNET 都不申请（纯离线） |

## minSdk 21 避坑

| API | 处理 |
|---|---|
| `StaticLayout.Builder`（API 23+） | ❌ 用老构造器 |
| `Html.fromHtml(String, flags)`（API 24+） | ❌ 用老签名 |
| `setJustificationMode`（API 26+） | ❌ 不用两端对齐 |
| `WindowInsetsController`（API 30+） | ❌ 用 systemUiVisibility |
| `setLetterSpacing`（API 21） | ✅ 可用 |
| API 21~25 图标 | 提供了非 adaptive icon 回退 |

## 已知限制

- **不支持带 DRM 加密的 epub**（市面购买的电子书多是此类）
- 非 UTF-8 编码的章节会乱码
- 复杂 CSS（class 选择器、表格、浮动）会被 `Html.fromHtml` 忽略
- 图片按屏宽缩放显示，超高图片跨页时可能被截断
- **多个章共享一个文件时**（Kindle 转换书），顶部章节名显示的是该文件首个目录条目，不会随阅读位置更新到子章
- 滑动翻页阈值固定为屏宽 22%，未提供灵敏度设置
- MVP 无：书签、夜间模式、搜索、翻页动画、按书封面展示的书架
